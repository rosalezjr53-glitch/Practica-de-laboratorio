# 02. Mapa de flujos críticos

1. El usuario puede crear una cuenta con correo y contraseña válidos y llegar a su lista de tareas.
2. El usuario puede iniciar sesión y consultar solo las tareas asociadas a su UID.
3. El usuario puede crear una tarea válida y verla en la lista.
4. El usuario puede marcar una tarea como completada o eliminarla y ver actualizado el listado.
5. El usuario puede cerrar sesión y volver a la pantalla de acceso.

La ruta principal es acceso → listado → nueva tarea → guardar → listado. Los estados vacíos, errores de validación y errores de servicio tienen mensajes visibles.
